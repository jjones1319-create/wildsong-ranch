# Fixes: what to type when a picture comes out wrong

Don't start over when a picture is close. Type one of these as your next message, in the same chat, and attach the approved `1-hero.png` again (or `grown-1-hero.png` for a grown form). Fill in the parts in [square brackets].

If only one small area is wrong, use ChatGPT's select or edit tool on the picture, paint over that area, and describe the fix. The rest of the picture stays as it is.

If a chat gets long and the pictures start to slip, open a **new chat** in the project, attach `1-hero.png` (and `chatgpt/style-anchor.png` for a hero), and paste the box you're on. A fresh chat with the right attachments is often the quickest fix.

---

## The design changed (drift)

```text
That changed the design. Go back to the attached approved image exactly: same proportions, shapes, markings, colours, eyes and level of detail. Only change [the view / the pose / the expression] as the prompt asked.
```

## A variant changed the shape

```text
The variant must be the same creature as the attached image, just repainted. Keep its shape, proportions, face and the layout of its markings exactly; change only the colours and the extras listed for the variant.
```

## The colours are off

```text
The colours are off. Use exactly these: [paste the Colours line from the box]. The [body] must clearly read as [#3FB6A8], not [lighter / greener / greyer]. Keep everything else the same.
```

## Not detailed enough (the important one)

```text
Push the detail much further, keeping the same design and colours: render it as a premium stylized 3D character. Fur in sculpted clumps and locks that follow the form, with fine individual strands at the edges and tips [or: crisp overlapping scales with a soft sheen / layered feathers with visible barbs / stone grain, chips and cracks]. Zoomed in, every surface should show real texture, never smooth plastic.
```

## Fur is messy or noisy

```text
The fur is too noisy. Group it into clear, sculpted clumps that follow the body's form, with fine strands only at the edges and tips, so the shapes stay clean and readable. Same design and colours.
```

## Too realistic or creepy

```text
Too realistic. Keep all the detail, but make it cuter and more stylized: a slightly bigger head, bigger glossy anime-style eyes, rounder, chunkier shapes, cleaner colours and soft, friendly lighting.
```

## Looks like a famous character

```text
This reads too much like a famous character. Keep my description, but make it clearly original: change [the ear shape / the head shape / the markings / the tail] to something of its own, and avoid any well-known silhouette or colour pattern.
```

## The style anchor leaked in

```text
You copied the creature from the style anchor. Use the anchor only for rendering style, detail level and lighting. The creature itself must follow my description: [its name], [one key feature], [its body colour].
```

## Wrong number of parts

```text
It has the wrong number of [legs / toes / ears / wings / horns / tentacles]. It must have exactly [number]. Keep everything else the same.
```

## Part of it is cut off

```text
Part of the creature is cut off. Zoom out so the whole creature fits, centred, with clear space all around it. Keep everything else the same.
```

## The turnaround has perspective, or the views don't line up

```text
These views must be orthographic, like a technical model sheet: no perspective, the camera exactly level, every view at the same scale and the same height, all standing on one shared ground line. Each view must show exactly the same creature from a different side.
```

## The face sheet is messy

```text
Use exactly 12 panels in a 4 by 3 grid, in this order: neutral, happy, tired, stressed, sad, angry, sleepy, sick, strain, dizzy, surprised, blink. The head must be the same size, angle and position in every panel; only the eyes, eyelids, brows and mouth change. A small lowercase label under each.
```

## Unwanted text, or the labels are garbled

```text
Remove all text except the small lowercase labels I asked for, and spell those exactly: [label, label, label].
```

## The background isn't plain

This one is only for the hero, turnaround, faces and details pictures. The poses sheet is meant to have a boulder and pool in panels 1–2, and turnarounds are meant to have faint guide lines.

```text
Make the background a plain, flat, even grey (#C4C8CF) with nothing on it. Keep the creature exactly the same.
```

## Lighting too dark or too dramatic

```text
Use soft, even studio lighting: a soft key light from the upper left, a gentle fill and a warm rim light. No dark, dramatic shadows. Keep the creature exactly the same.
```

## The poses changed the creature

```text
In every panel the creature must be identical to the attached approved image: same proportions, markings, colours and detail. Only the pose changes.
```
