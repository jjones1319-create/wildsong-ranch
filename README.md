# Wildsong Ranch

*Every monster is born from a song.*

Type any song title, name or phrase at the Shrine of Echoes and a singing stone wakes the monster that was listening for it. Raise it week by week: train it, feed it, praise it (or scold it), take it on journeys and expeditions, and battle your way from rookie cups to the four Crowns of Wildsong Vale. When its long life ends, its Heartstone and its lineage carry on.

- **Play:** https://jjones1319-create.github.io/wildsong-ranch/
- **Install on your phone:** open the link, then *Share → Add to Home Screen* (iPhone) or *⋮ → Install app* (Android).
- **Power up:** teach new attacks with **Songsheets** and boost stats with **Stat Sweets**. Use as many as you like.
- **Monster Lab:** create, load and edit any monster's stats and attacks, including the one you're raising. Share monsters with a code or QR, and pit any two against each other.

## Built with
Vite · TypeScript · Preact · procedural SVG art · ZzFX sound · an installable, offline-capable web app on GitHub Pages.

The project docs are in `docs/`: game design, content, build plan and research notes. `CLAUDE.md` holds the standing instructions for the AI coding assistant that builds it.
